## Overview

Goodhertz Panpot is a powerful stereo panning plugin offering multiple pan laws, mid/side control, binaural processing, and stereo image manipulation beyond a simple balance knob.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Goodhertz Panpot** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Pan Law** | Selectable -3 dB, -4.5 dB, and -6 dB constant-power pan laws |
| **Mid/Side** | Independent mid and side level and balance control |
| **Binaural** | Headphone binaural processing for spatial depth on stereo sources |
| **Width** | Stereo width narrowing and widening with phase coherence preservation |
